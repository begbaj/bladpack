# 0.2.5 by begbaj on Sep 27, 2026

- Security fix (1): up to the previous version, Bladpack shipped with a pre-generated `web_server.json` configuration containing a pre-generated API key. This is safe as long as you don't expose the server to the internet (which you usually do when playing with friends). I've now removed this file; it will be auto-generated by KubeJS on its first launch.

- Security fix (2): similar to Security fix (1), Bladpack shipped with a pre-generated encryption key for the NoChatReports mod. That file has been removed and will now be regenerated on every install.

- Removed per-player data that was accidentally shipped with the pack: EMI lookup/craft history, Inventory Profiles Next per-world and per-server data, and a few generated cache files. Your own EMI and IPN data is no longer overwritten on install.

- New mod: Armor Model API (now required by the RPG Series mods)

- Sodium: pinned to stable. Sodium Options API and Sodium Dynamic Lights only support Sodium 0.6:
  - Iris: pinned to 1.8.12
  - Sodium Extra: pinned to 0.6.0
  - Reese's Sodium Options: pinned to 1.8.3
  - More Culling: pinned to 1.0.7

- Neoforge and many mods updated

# Blad a1.4.2-0 by begbaj on Dec 22, 2024

- Removed Nature's Compass
- Configuration tweaks to make the modpack more challenging:
  - FallingTree: setting tweaks
  - Artifacts: some items tweaked to be more challenging
  - Carry On: higher slowness multiplier, and carried entities drop when you are hit
  - Traveler's Backpack: higher slowness debuff rate
  - Traveler's Backpack: significantly decreased spawn chance on mobs
  - Waystones: 312 chunks between wild waystones, and they no longer spawn in villages (4,992 blocks apart)
- Crafting tweaks:
  - Traveler's Backpack: shulker boxes instead of chests in the recipe
  - Mekanism: Osmium Compressor is significantly harder to craft (requires a block of netherite)
  - Mekanism: Portable Teleporter requires a warp stone instead of a teleportation core
  - Waystones: Warp Stone is harder to craft (requires a Mekanism teleportation core instead of an emerald)
- Added the Blad resource pack, used only to show recipes EMI was hiding (potion crafting and enchanted books)
